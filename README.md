# Corne v4 macOS data engineering / DevOps configuration

This repository builds a four-layer, 42-key Corne v4 layout for data engineering and DevOps work on macOS. It uses plain QWERTY, dedicated modifiers, and dedicated layer keys: there are no home-row modifiers, mod-taps, layer-taps, combos, or timing-dependent letters.

ZMK is pinned to the known-good revision `6e2ef41e022d555b10f116e395832913f71717b3`. The preserved build matrix uses `nice_nano/nrf52840/zmk` with `corne_left` and `corne_right`, producing `corne_v4_left` and `corne_v4_right` artifacts.

## Layers

`RAISE` provides Python/data/ops symbols, `LOWER` provides navigation/numbers and terminal prefixes, and holding both selects guarded `ADJUST`/System controls.

### Base — plain QWERTY

| Row | Left six positions | Right six positions |
|---|---|---|
| Top | `ESC` `Q` `W` `E` `R` `T` | `Y` `U` `I` `O` `P` `BACKSPACE` |
| Home | `TAB` `A` `S` `D` `F` `G` | `H` `J` `K` `L` `;` `'` |
| Bottom | `LEFT SHIFT` `Z` `X` `C` `V` `B` | `N` `M` `,` `.` `/` `RIGHT CTRL` |
| Thumbs | `OPTION` `RAISE` `COMMAND` | `SPACE` `LOWER` `ENTER` |

Option and Command are dedicated macOS thumb modifiers; Shift and Control remain dedicated edge keys.

### Lower — navigation and numbers

| Row | Left six positions | Right six positions |
|---|---|---|
| Top | `` ` `` `1` `2` `3` `4` `5` | `6` `7` `8` `9` `0` `DELETE` |
| Home | `VIM` `CTRL` `OPTION` `COMMAND` `SHIFT` `TMUX` | `LEFT` `DOWN` `UP` `RIGHT` `PAGE DOWN` `PAGE UP` |
| Bottom | `F1` `F2` `F3` `F4` `F5` `F6` | `F7` `F8` `F9` `F10` `F11` `F12` |
| Thumbs | `CTRL` `RAISE` `COMMAND` | `SPACE` `LOWER` `ENTER` |

`VIM` invokes `&vim_window_prefix`, which taps and releases Vim's `Ctrl-W`; `TMUX` invokes `&tmux_prefix`, which taps and releases stock tmux `Ctrl-B`. While continuing to hold Lower, follow either prefix with the H/J/K/L arrow positions. Releasing Control in each macro prevents the next arrow from becoming a Control-arrow chord. Ordinary layer modifiers also support macOS word, line, document, and selection navigation.

### Raise — Python/data/ops symbols

| Row | Left six positions | Right six positions |
|---|---|---|
| Top | `~` `!` `@` `#` `$` `%` | `^` `&` `*` `(` `)` `?` |
| Home | `-` `CTRL` `OPTION` `COMMAND` `SHIFT` `=` | `[` `{` `:` `|` `}` `]` |
| Bottom | `\` `'` `"` `_` `+` `` ` `` | `<` `>` `,` `.` `/` `;` |
| Thumbs | `CTRL` `RAISE` `COMMAND` | `SPACE` `LOWER` `ENTER` |

The right home row groups common Python, SQL, YAML/JSON, Terraform/HCL, shell, Docker, and Kubernetes delimiters/operators. Quotes, underscore, comments, decorators, comparisons, pipe, slash, backslash, dollar, and backtick are direct rather than generated by workflow-specific macros.

### Adjust — guarded System controls

| Row | Left six positions | Right six positions |
|---|---|---|
| Top | `BOOT` `BT 1` `BT 2` `BT 3` `BT 4` `BT 5` | `CAPTURE` `CAPS WORD` `CAPS LOCK` `SPOTLIGHT` `APP SWITCHER` `LOCK` |
| Home | `BT CLEAR` `MEDIA PREV` `PLAY/PAUSE` `MEDIA NEXT` `MUTE` `VOL DOWN` | `NONE` `NONE` `NONE` `NONE` `NONE` `NONE` |
| Bottom | `RESET` `BRIGHTNESS DOWN` `BRIGHTNESS UP` `USB` `BLE` `VOL UP` | `OUTPUT TOGGLE` `NONE` `NONE` `NONE` `NONE` `NONE` |
| Thumbs | `CTRL` `RAISE` `COMMAND` | `SPACE` `LOWER` `ENTER` |

The exact macOS bindings are `&kp LG(LS(N5))` for capture, `&kp LG(SPACE)` for Spotlight, `&kp LG(TAB)` for app switching, and `&kp LC(LG(Q))` for lock. Caps Word and Caps Lock are adjacent.

Bootloader remains guarded at physical `ESC`, reset at physical `LEFT SHIFT`, profiles at `Q`–`T`, and Bluetooth clear at `TAB`. Output controls remain `&out OUT_USB`, `&out OUT_BLE`, and `&out OUT_TOG` at physical `C`, `V`, and `N`. All unavailable System positions use `&none`, so base actions cannot leak through.

RGB underglow is disabled. The keymap intentionally has no RGB include, binding, LED-chain override, or scan/debounce override; former RGB positions are blocked with `&none`.

## USB, BLE, and configuration safety

`config/corne.conf` keeps encoder/RGB policy, display and power behavior, connection preferences, and pinned defaults for report, scan, and split queues. It avoids speculative low-level PHY, ACL, data-length, GATT, and deprecated debounce changes.

At the pinned revision, `config/corne_left.conf` and `config/corne_right.conf` load after the shared config. The left central enables USB and BLE, HKRO, basic consumer usages, and `CONFIG_ZMK_USB_BOOT=y` for conservative pre-OS/recovery compatibility. The right half remains BLE-only and forwards key positions to the central; it is not a standalone USB keyboard.

The output controls select the central's preferred host transport. Pinned ZMK falls back to the other ready transport if the preferred one is unavailable. Bluetooth profile selection affects host pairing, not the right-to-left split link. ZMK Studio remains disabled.

Only flash these artifacts to compatible Corne v4 hardware. Use the artifact matching each half, then test all base keys, both layer thumbs, Vim/tmux prefixes, output selection, Bluetooth pairing, and guarded boot/reset positions. Static validation cannot verify wiring, batteries, radio conditions, host shortcuts, or flashing.

## Building

The GitHub Actions workflow validates the repository and builds both matrix entries. Equivalent commands in an initialized ZMK/west workspace are:

```sh
west build -s zmk/app -d build/corne_left -b nice_nano/nrf52840/zmk -- -DSHIELD=corne_left -DZMK_CONFIG="$PWD/config" -DZMK_EXTRA_MODULES="$PWD"
west build -s zmk/app -d build/corne_right -b nice_nano/nrf52840/zmk -- -DSHIELD=corne_right -DZMK_CONFIG="$PWD/config" -DZMK_EXTRA_MODULES="$PWD"
```

Each command writes `zephyr/zmk.uf2` below its build directory. Artifact labels are CI names, not local output filenames.

## Dependency reproducibility status

`config/west.yml` and the reusable workflow pin ZMK to `6e2ef41e022d555b10f116e395832913f71717b3`; update both only after building both halves. The repository's verified baseline records that both `corne_left` and `corne_right` completed full pinned-source firmware builds. This change is locally statically validated unless a new build is explicitly reported.


The checks validate all four exact 42-binding layers, both prefix macros, macOS shortcuts, guarded controls, disabled RGB/debounce policy, docs, target configs, build metadata, and dependency pins. See [KEYMAP.md](KEYMAP.md) for usage details.
